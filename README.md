# Replication code for "Perseverance, cognitive skills and life outcomes"


This repository contains the Stata code accompanying the paper Fé and Jahangir (2026), *Journal of Economic Behavior &
Organization* in 2026.

## Contents

-   `analysis_weights_LE.do`: Main Stata script for the analysis using
    survey weights.

## Requirements

-   **Stata 15 or newer**
-   The **British Cohort Study (BCS70)** data used in the paper, with
    access obtained separately.

## Running the code

1.  Obtain the required BCS70 data.
2.  Open `analysis_weights.do` in Stata.
3.  Update the file paths and, if necessary, variable names to match
    your local data setup.
4.  Run the script.

The dataset is not included in this repository. Successful execution
therefore depends on having access to the required data and configuring
the paths appropriately.
